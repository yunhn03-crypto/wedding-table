사용 방법

  1. 상단에서 Garden / 1층 / 2층을 선택합니다.
  2. 1층과 2층은 도면의 테이블 박스를 클릭합니다.
  3. Garden은 로드 방향과 테이블 모양을 고른 뒤 빈 공간을 클릭합니다.
  4. Garden 테이블은 드래그로 이동합니다.
  5. Garden 테이블을 한 번 클릭하면 삭제됩니다. 사각 테이블은 ↻ 버튼을 마우스로 드래그해 원하는 각도로 회전합니다.
  6. 음주류 버튼에서 웰컴드링크, 주류, 음료 수량을 선택합니다.
  7. 요청사항 버튼에서 추가 요청사항을 입력합니다.
